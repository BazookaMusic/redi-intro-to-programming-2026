# Exercise 7: Times-table tower 🏰

🟡 Intermediate · Exercise 7 of 10 · [All exercises](../README.md)

A **nested loop** is a loop inside another loop. The first `for` is the **outer loop**. The indented `for` inside it is the **inner loop**. Each time the outer loop runs once, the inner loop runs all the way through.

**Task:** In `exercise.py`, print the times tables for 1, 2 and 3, from × 1 to × 5. Print a heading before each table.

**Rule:** Use for loops.

**Expected output:**

```text
Table of 1
1 x 1 = 1
1 x 2 = 2
1 x 3 = 3
1 x 4 = 4
1 x 5 = 5
Table of 2
2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
2 x 4 = 8
2 x 5 = 10
Table of 3
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15
```

<details>
<summary>Hint</summary>

- Two numbers change in the output: the table (1 to 3) and the number you multiply by (1 to 5). Which one changes faster?
- The heading is printed once for each table. Which loop should print it?

</details>
