# Exercise 2: Fruit salad 🍎

🟢 Beginner · Exercise 2 of 10 · [All exercises](../README.md)

A **list** holds several values in one variable. Write it with square brackets `[ ]` and put commas between the items:

```python
fruits = ["apple", "banana", "cherry"]
```

A for loop can go through a list one item at a time. You do not need `range()` for this.

**Task:** In `exercise.py`, create the `fruits` list above. For each fruit, print `I like` and the fruit.

**Rule:** Use a for loop.

**Expected output:**

```text
I like apple
I like banana
I like cherry
```
