# Exercise 1: Counting sheep 🐑

🟢 Beginner · Exercise 1 of 10 · [All exercises](../README.md)

New to for loops? Read the [key words](../README.md#key-words) first.

`range()` gives whole numbers for a loop. `range(start, stop)` starts at `start` and stops **before** `stop`. The `stop` number is never included.

For example, `range(2, 5)` gives `2`, `3`, `4`.

**Task:** In `exercise.py`, print the numbers from 1 to 5, one per line.

**Rule:** Use a for loop.

**Expected output:**

```text
1
2
3
4
5
```

<details>
<summary>Hint</summary>

`range()` never includes its `stop` number. Which `stop` number makes the last number 5?

</details>
