# Exercise 3: Shopping basket 🛒

🟢 Beginner · Exercise 3 of 10 · [All exercises](../README.md)

A **running total** is a sum that grows step by step. It starts at `0`. Each time the loop runs, you add the next number to it.

**Task:** These are the prices of your shopping. The list is already in `exercise.py`:

```python
prices = [4, 10, 3, 7]
```

Add up the prices. After each price, print the total so far. At the end, print the final total.

**Rule:** Use a for loop.

**Expected output:**

```text
Total so far: 4
Total so far: 14
Total so far: 17
Total so far: 24
Final total: 24
```
