## Homework

### Homework 1: Expression or statement?

1. `7 * 6`: **expression**, it becomes `42`
2. `price = 19.99`: **statement**, it stores `19.99` in `price`
3. `abs(-4)`: **expression**, it becomes `4`
4. `print("Hello")`: **statement**, it shows `Hello`
5. `round(3.14159, 2)`: **expression**, it becomes `3.14`
6. `total = price * 1.21`: **statement**, it stores the result in `total`
7. `(70 + 85 + 90) / 3`: **expression**, it becomes `81.666...`
8. `score += 3`: **statement**, it adds 3 to `score`

Bonus: `price * 1.21` is the expression. Python evaluates it first, then the statement stores the result in `total`.
