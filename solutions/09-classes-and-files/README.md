# Classes and files: solutions

Try the [exercises](../../exercises/09-classes-and-files/README.md) first.
Each task folder contains a solved `exercise.py`. To check it, copy it and the
matching student `check.py` into a separate folder, then run `check.py`.

## Classroom exercises

### Predict the output

```text
3
Bella 6
```

- `bella.age = 6` changes only Bella's age.
- Rex is a different object, so his age is still `3`.

```text

```

- The last `"a"` added `eggs` at the end.
